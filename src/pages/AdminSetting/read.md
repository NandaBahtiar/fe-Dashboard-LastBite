Buatkan komponen React dengan Tailwind CSS untuk halaman pengaturan admin dengan fitur-fitur berikut:

**Layout & Struktur:**

*   Container utama dengan beberapa bagian (card) untuk setiap kategori pengaturan.
*   Setiap card memiliki judul, deskripsi, dan form input yang relevan.

**Bagian Pengaturan:**

1.  **Informasi Profil:**
    *   Form untuk mengubah nama, email, dan nomor telepon.
    *   Avatar yang dapat diubah dengan klik.
    *   Button "Simpan Perubahan".

2.  **Ubah Kata Sandi:**
    *   Form untuk memasukkan kata sandi saat ini, kata sandi baru, dan konfirmasi kata sandi baru.
    *   Button "Ubah Kata Sandi".

3.  **Preferensi Notifikasi:**
    *   Checkbox untuk mengaktifkan/menonaktifkan notifikasi email untuk berbagai event (misalnya, transaksi baru, pendaftaran mitra baru).
    *   Button "Simpan Preferensi".

4.  **Pengaturan Komisi:**
    *   Form untuk mengatur persentase komisi aplikasi.
    *   Input numerik untuk nilai komisi.
    *   Button "Simpan Komisi".

**Styling Details:**

*   Gunakan card dengan shadow dan rounded corners untuk setiap bagian.
*   Input fields dengan styling yang konsisten.
*   Button dengan warna primary (misalnya, biru atau hijau) dan hover effects.

**Responsivitas:**

*   Layout beradaptasi dengan baik di berbagai ukuran layar.
*   Form input dan button mudah digunakan di perangkat mobile.

Gunakan Tailwind CSS untuk semua styling dan buat komponen yang fully functional dengan state management untuk setiap form.
